🚀 Endpoints Principaux

POST /api/auth/login
Authentification utilisateur
GET /api/dashboard
Données du tableau de bord
GET /api/sorties
Liste des sorties conteneur
POST /api/sorties
Créer une nouvelle sortie
GET /api/vehicules
Liste des véhicules
GET /api/operations?statut=en_cours
Liste des opérations en cours
GET /api/detentions?statut=active
Liste des détentions actives
POST /api/primes/payer-en-lot
Payer plusieurs primes en une fois

📝 Format des Réponses

Succès

{
  "success": true,
  "message": "Opération réussie",
  "data": { ... }
}

Erreur

{
  "success": false,
  "message": "Message d'erreur",
  "errors": {
    "field": ["Erreur validation"]
  }
}
⚠️ Important: Toutes les routes protégées nécessitent un Bearer Token dans le header Authorization.
Format: Authorization: Bearer {votre_token}

📊 Codes HTTP

  • 200 - Succès
  • 201 - Créé avec succès
  • 204 - Supprimé avec succès
  • 400 - Requête invalide
  • 401 - Non authentifié
  • 403 - Non autorisé
  • 404 - Ressource non trouvée
  • 422 - Erreur de validation
  • 500 - Erreur serveur
